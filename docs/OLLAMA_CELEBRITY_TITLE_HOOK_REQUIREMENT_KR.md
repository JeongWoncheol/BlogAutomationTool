# Ollama 연예인 착장 제목 생성 규칙

연예인 착장 원고의 제목은 검색형 키워드와 강한 클릭 후킹을 동시에 사용한다.

- 제목 앞부분에는 반드시 `연예인명 + 패션 유형`을 넣는다.
  - 예: `OOO 공항패션`, `OOO 사복패션`, `OOO 출근길패션`, `OOO 행사패션`
- 제목 뒷부분은 핵심 착장 아이템 1~3개와 강한 반응형 후킹을 결합한다.
- 매번 같은 문장을 반복하지 않고 최소 수십 개의 후킹 패턴을 문맥에 맞게 다양하게 변형한다.
- 검색 키워드만 나열하거나 광고 문구처럼 딱딱한 제목은 금지한다.
- 후킹 예시: `와 이 코디 뭐야?`, `사진 보자마자 저장`, `그냥 기본템인데 분위기가 다 했다`, `왜 이렇게 예쁘지?`, `이건 그대로 따라 입고 싶다`, `가방 하나로 분위기 확 달라졌다`, `꾸민 건 없어 보이는데 자꾸 눈이 간다`.
- 제목은 검색성과 클릭성을 동시에 확보하되 과도한 낚시성·허위 단정은 피한다.
