# BlogAutomationTool

Naver Blog Automation Studio **v8.08.52** source tree for collaborative development.

## Main features
- Product/trend collection and content workflow
- Exact-product 3-image collection with Coupang / NAVER Image API HUB / Google fallback validation
- Naver SmartEditor draft automation
- Ollama local AI content generation with conversational Korean tone checks
- Celebrity outfit trend discovery and evidence-assisted analysis
- Toss / Coupang / NAVER integration helpers
- Optional local video workflow

## Quick start on Windows
1. Run `01_INSTALL.cmd`
2. Run `15_INSTALL_NORMAL_CHROME_EXTENSION.cmd`
3. Configure only the integrations you use
4. Run `START_STUDIO.cmd`

Credentials, browser state and local databases are intentionally excluded. Current collaborative baseline: **v8.08.52**.
