NBlog Studio 기능 한눈에 보기 · 권장 실행 순서

1. 계정·연결
- OpenAI, 쿠팡, 네이버, 토스 API 연결 상태를 확인합니다.
- 네이버 저장환경 사전점검과 Chrome 확장 설치/갱신을 실행합니다.

2. 수집
- ‘수집 센터’에서 쿠팡·토스·네이버 3사 수집과 아이템스카우트·네이버 데이터랩 트렌드 수집을 같은 화면에서 실행합니다.
- 3사별 수집 건수와 트렌드 진행률, 후속 원고·이미지·검증 진행률을 한 화면에서 확인합니다.
- 외부 원고는 개수 제한 없이 ‘폴더 선택·가져오기’ 또는 ZIP 가져오기를 사용합니다.
- 기존 게시글 제외 기능으로 수동 게시완료/네이버 기존글 자동대조를 적용합니다.

3. 작성
- Ollama Qwen3 무료 로컬 AI를 제목·본문·태그 생성 1순위로 사용합니다. OpenAI 자동사용은 기본 OFF입니다.
- 제휴링크 무클릭 생성으로 이미지3장 완료 상품의 링크를 준비합니다.
- 동일상품 사진 3장은 대표/갤러리→상세→Google 동일상품 원본페이지 순으로 정확도를 우선합니다.

4. 영상 기획
- ‘영상 → Ollama 영상 기획 · 생성’에서 상품을 선택하면 Qwen3가 콘셉트·타깃·훅·CTA·12컷을 기획합니다.
- 영상 기획은 Ollama 로컬 AI라 API 비용이 없습니다. 실제 렌더링은 ComfyUI + FFmpeg를 사용합니다.

5. 검증
- 이미지·가격 검증과 SEO/중복/원고 품질검수를 실행합니다.
- 틀린 이미지로 3장을 억지로 채우지 않고 미완료로 남깁니다.

6. 네이버 임시저장
- 사진 3장 완료만 임시저장 또는 텍스트만 임시저장을 선택합니다.
- 실패 시 마지막 임시저장 실패 재시도를 사용합니다.
- 반복 실패 분석은 실패 진단 폴더에서 CSV/HTML/PNG를 확인합니다.

7. 빠른 운영
- 대시보드에서 전체상품, 원고준비, 사진3장 완료, 임시저장 준비, 기존 게시 제외 건수를 확인합니다.
- ‘다음 할 일 자동안내’를 누르면 현재 상태 기준 권장 작업을 안내합니다.

[V8.08.42 Google 동일상품 이미지 복구]
- Google 일반검색만 보던 기존 방식을 Google 이미지검색 + 웹검색 병행으로 변경했습니다.
- Google 썸네일은 저장하지 않고, imgrefurl/source page와 원본 imgurl만 후보로 사용합니다.
- 원본 상품페이지를 다시 열어 상품명/모델/용량/수량을 검증한 뒤에만 이미지를 저장합니다.
- srcset/data-src/zoom image/JSON-LD/OG image/CSS background/지연로딩 이미지를 다중 스캔합니다.
- 다운로드가 막히면 동일 검증 페이지를 CDP로 렌더링해 제품 이미지 영역을 화면 크롭으로 보강합니다.
- 쿠팡/토스에서 동일상품을 못 찾더라도 Google 원본페이지가 정확히 검증되면 대표 1장 + 보조 2장까지 구성할 수 있습니다.
- 이미지 단계 중 Google 검색/원본페이지 검증/렌더링 보강 상태가 실시간 진행표시에 표시됩니다.

- Google 원본페이지는 제목/H1/OG/Product JSON-LD 상품명 필드가 실제 상품명·모델·용량·수량과 일치해야 통과합니다.
