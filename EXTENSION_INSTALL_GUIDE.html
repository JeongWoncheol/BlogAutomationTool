일반 Chrome 수집 확장프로그램 설치

1Chrome 사용자 선택

평소 네이버·쿠팡·토스를 사용하는 Chrome 프로필을 선택합니다.

2개발자 모드 켜기

chrome://extensions/ 화면 우측 상단의 개발자 모드를 켭니다.

3압축해제된 확장 프로그램 로드

좌측 상단의 압축해제된 확장 프로그램을 로드합니다를 클릭합니다.

4chrome_extension 폴더 선택

프로그램 폴더 안의 chrome_extension 폴더 자체를 선택하고 폴더 선택을 누릅니다.

5설치 확인

NaverBlog Normal Chrome Collector 카드가 보이고 우측 스위치가 켜져 있어야 합니다.

중요: ZIP 파일 자체를 선택하면 안 됩니다. 압축을 완전히 풀고, 그 안의 chrome_extension 폴더를 선택해야 합니다.
